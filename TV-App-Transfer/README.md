# TV-App-Transfer

Apps auf **Samsung-Fernseher** bringen (umwandeln, signieren, installieren) – oder APKs direkt auf einen
**Android-TV-Stick** (Fire TV, Google TV) am Fernseher. Für Windows-PC und Android-Handy.

## Installieren
- **PC:** Setup ausführen; bei der Windows-Warnung „Weitere Informationen“ → „Trotzdem ausführen“.
- **Handy:** APK antippen, herunterladen, installieren (einmalig „Installation aus unbekannten Quellen“ erlauben).
- **Updates:** Beide Apps melden neue Versionen selbst („Nach Updates suchen“, automatisch alle 24 Stunden).
  Zertifikate, Geräte und Einstellungen bleiben erhalten.

## Erste Schritte
1. Samsung-Fernseher: **Apps** öffnen → **1 2 3 4 5** → Entwicklermodus **EIN** → IP-Adresse des PCs/Handys eintragen → Fernseher neu starten.
2. Programm öffnen → Datei hineinziehen (APK, .wgt) oder Webadresse eingeben → **Im WLAN suchen** → **Übertragen**.
3. Beim ersten Mal einmalig mit dem kostenlosen Samsung-Konto anmelden (offizielle Samsung-Seite).

Normale Android-Apps laufen nicht auf Samsung-Fernsehern (Tizen). Das Programm erkennt das und überträgt sie
stattdessen auf einen Android-TV-Stick am Fernseher.
